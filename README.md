# Side A App Store 지원 사이트

이 폴더를 GitHub의 공개 저장소 `asg0416/side-a` 루트에 게시하고 GitHub Pages를 활성화하면 다음 주소를 사용할 수 있습니다.

- 홈페이지: `https://asg0416.github.io/side-a/`
- 개인정보 처리방침: `https://asg0416.github.io/side-a/privacy/`
- 고객지원: `https://asg0416.github.io/side-a/support/`

App Store Connect에는 개인정보 처리방침과 고객지원 주소를 각각 입력합니다. 공개 후에는 로그아웃한 브라우저에서도 두 주소가 열리는지 확인합니다.
