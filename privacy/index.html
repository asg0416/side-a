수집하는 정보

Side A는 개인정보나 사용 데이터를 수집하지 않습니다. 회원가입, 로그인, 광고, 분석 도구 및 개발자가 운영하는 서버가 없습니다.

음악 파일과 보관함

음악 파일은 사용자가 직접 선택한 Mac의 폴더에 그대로 유지됩니다. 앱은 재생과 정리를 위해 해당 폴더에 접근하며, 보관함 정보와 앱 설정은 사용자의 Mac 안에 저장됩니다. 개발자에게 음악 파일, 파일 이름, 가사 또는 보관함 정보가 전송되지 않습니다.

폴더 접근 권한

Side A는 macOS App Sandbox 안에서 동작합니다. 사용자가 파일 선택 창에서 허용한 폴더만 보안 범위 북마크를 통해 다시 접근합니다. 사용자는 앱에서 폴더 연결을 해제하거나 macOS 설정에서 권한을 변경할 수 있습니다.

음성 인식

실험적 가사 자동 싱크 기능을 직접 실행한 경우에만 macOS 음성 인식 권한을 요청합니다. 이 기능은 기기 내 음성 인식이 지원되는 언어에서만 동작하도록 구성되어 있으며, Side A가 음원이나 인식 결과를 개발자 서버로 전송하지 않습니다.

제3자 제공과 추적

Side A는 개인정보를 제3자에게 판매하거나 제공하지 않으며, 여러 앱이나 웹사이트에 걸쳐 사용자를 추적하지 않습니다.
